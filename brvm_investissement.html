📋 Coller les données depuis BRVM.org

Mode d'emploi :
  1. Allez sur brvm.org → Marché → Cours des actions
  2. Sélectionnez tout le tableau de cours (Ctrl+A dans le tableau)
  3. Copiez (Ctrl+C)
  4. Collez ci-dessous (Ctrl+V) et cliquez "Analyser et importer"

📑 Analyser le Bulletin de Cotation BRVM (PDF)

  1. Allez sur brvm.org → Publications → Bulletins de cotation
  2. Téléchargez le dernier bulletin (fichier PDF du jour)
  3. Déposez-le dans la zone ci-dessous — l'app analyse et extrait les cours automatiquement
